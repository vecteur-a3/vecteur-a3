## 1. FTC Affiliate & Commercial Disclosure (16 CFR Part 255)

In compliance with the **Federal Trade Commission (FTC) Guides Concerning the Use of Endorsements and Testimonials in Advertising (16 CFR Part 255)** and partner Acceptable Use Policies:
* **Reader-Supported Research:** Some outbound links leading to software vendors evaluated on this website (such as Simple Analytics or Fathom Analytics) are partner referral links. If you click on a partner link and subscribe to a paid software tier, we may earn a referral commission at **no additional cost to you**.
* **Editorial Independence & Three-Option Comparisons:** Referral partnerships never influence the technical specifications we report. Every comparison report evaluates **three real-world software solutions** side by side using exclusively the technical parameters documented by each vendor in its official documentation as of the stated verification date.
* **Single Call-To-Action Policy:** To preserve editorial clarity, each technical audit contains a single primary partner Call-To-Action clearly labeled as a sponsored partner link.

## 2. Website Analytics & Visitor Privacy Architecture

Because our publication audits privacy-friendly web analytics platforms, we maintain full transparency regarding our own telemetry stack:
* **Analytics Solution Used on This Portal:** This website is configured to use **Plausible Analytics** — a European-hosted, cookieless web analytics platform — to measure aggregate pageviews, referring domains, and outbound documentation clicks.
* **No Browser Cookies or Cross-Site Tracking:** According to Plausible Analytics' official technical documentation, visitor measurement operates without setting browser cookies, writing to local storage, or collecting persistent cross-site identifiers.
* **Infrastructure & Hosting Logs:** As a statically generated website hosted on **GitHub Pages** (GitHub, Inc.), standard HTTP request metadata (such as visitor IP addresses and User-Agent headers) is processed at the network edge by the hosting provider for security, rate-limiting, and DDoS mitigation in accordance with the official GitHub Privacy Statement. We do not claim that accessing any web server involves "zero network data transmission."
